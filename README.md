Once Upon A Time: Lost Media Archive

Welcome to the Once Upon A Time: Lost Media Archive, an immersive, interactive digital experience designed as a "UIC Radio Archival Division" terminal. This project allows users to navigate through various declassified operative profiles to "rescue" lost media and stories from oblivion.
Project Overview

This web project is a themed portal that blends interactive UI elements with a narrative-driven archival experience. It utilizes custom animations, CSS effects, and a modular design to create a retro-futuristic atmosphere.
Core Experience

    Entry (Landing Page): Access the "UIC Radio Archival Division" terminal.

    Navigation (The Hub): Explore different operative profiles, including AJ and Maria.

    Operative Archives: Each profile features unique interactive elements, such as vinyl players, photo galleries (utilizing the 7.css Windows 95 style), and personality-driven bios.

    Conclusion: Reach the "Final" mission page to accept your role as an Archivist.

 Technical Stack

This project is built using standard web technologies with a focus on immersive styling:

    HTML5 & CSS3: Structural and presentational foundation.

    JavaScript: Powers interactive elements like navigation, modal/tab handling (Maria's page), and custom animations.

    CSS Animations: Keyframe animations drive the unique look, including "pulse" effects, "spin" effects for vinyl players, and "glitch" effects for thematic UI components.

    External Assets:

        Fonts: Roboto, Open Sans, Cedarville Cursive (via Google Fonts).

        Libraries: 7.css (used for Maria's Windows 95 aesthetic).

 File Directory

 Design Highlights

    Retro UI: The use of 7.css on Maria’s page adds a distinct "Windows 95" nostalgic feel, contrasting with the sleek, dark-mode styling of the other pages.

    Thematic Polish: The project uses consistent color palettes (Gold/Deep Blue for the archive, Neon/Void colors for the final page) to establish distinct zones of the experience.

    Interactive Elements: Features like the vinyl record player animation and the "flashlight" beacon on the final page create an engaging user journey.
 Deployment

This project is configured as a static site, intended for deployment on hosting platforms like GitHub Pages. Ensure all asset paths (images, audio files like AreYouReady.mp3 and Fire.wav) are correctly mapped relative to the index.html and profile pages.
